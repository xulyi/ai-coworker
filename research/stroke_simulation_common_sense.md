# 脑卒中康复模拟数据：指标耦合常识文档

> 本文档基于 FMA-LE（下肢版）官方手册、BBS 指南、Barthel Index 原始量表、MAS 标准及 CSS 定义，结合文献中的相关系数与回归关系整理而成。用途：为模拟数据生成提供**规则之外的常识校验层**。

---

## 一、各量表的结构与临床意义

### 1. FMA-LE（Fugl-Meyer Assessment Lower Extremity）
- **总分 0–34 分**，评估下肢运动功能+反射+协调速度。
- **关键里程碑（基于 Brunnstrom 恢复阶段）**：
  - **0–7 分**：协同运动期（屈肌/伸肌协同主导），无法完成单关节独立运动。
  - **8–15 分**：坐位下开始脱离协同（膝屈>90°、踝背屈），但站立位控制极差。
  - **16–21 分**：站立位可完成膝屈/踝背屈，但需扶撑或伴髋屈代偿，**分离运动尚未完全建立**。
  - **≥22 分**：**分离运动大关**。患者可在站立位完成≥90°膝屈且保持髋伸展，或完成无代偿的踝背屈。这是从"不能独立控制关节"到"能独立控制关节"的质变。
  - **≥28 分**：分离运动较成熟，精细协调与速度接近正常。

### 2. BBS（Berg Balance Scale）
- **总分 0–56 分**，14 项任务，评估静态与动态平衡。
- **关键 cutoff（多篇文献共识）**：
  - **<21**：极高跌倒风险，**无法无支撑站立**，TUGT 应为 N/A 或无法完成。
  - **21–36**：跌倒风险高，可独立坐位/站位转身，但步态底盘不稳。
  - **≥29**：被广泛证实为**恢复社区行走能力（community ambulation）的最强预测因子**（OR≈1.11）。
  - **≥38**：平衡功能已足以支持较快速、安全的步态转移。
  - **41–56**：跌倒风险显著降低，可独立完成复杂平衡任务。

### 3. ADL / Barthel Index（或 Modified Barthel Index）
- **总分 0–100（原始版）或 0–20（MBI）**，10 项自理能力。
- **与下肢功能直接相关的两项**：

| 项目 | 评分细则 | 功能含义 |
|------|----------|----------|
| **Mobility（平地移动）** | 0=卧床/不能移动；5=轮椅独立>50米；10=需1人辅助步行>50米；15=独立步行（可用辅具） | 与 FMA-LE、BBS 直接挂钩 |
| **Stairs（上下楼梯）** | 0=不能；5=需帮助；10=独立 | 需要比平地步行更高的分离运动与平衡控制 |

- **功能解锁关系**：
  - 当患者从"轮椅"（5分）升级到"辅助步行"（10分）再到"独立步行"（15分）时，FMA-LE 通常已跨过分离运动阈值（≥22），BBS 通常已≥29。

### 4. TUGT（Timed Up and Go Test）
- **时间越短 = 功能越好**，与 BBS、FMA-LE、gait speed 高度负相关。
- **文献相关系数**：
  - TUGT ↔ BBS：r ≈ **-0.52 ~ -0.815**（强负相关）
  - TUGT ↔ gait speed：r ≈ **-0.61 ~ -0.646**
- **功能分层（常识推断）**：
  - BBS < 21 → **TUGT = N/A**（无法完成测试）。
  - BBS 21–36 → 可完成测试，但步态底盘不稳，耗时通常**>35 秒**。
  - BBS ≥ 38 且 FMA-LE ≥ 21 → 步态质量 достаточно 好，TUGT 才可能**<25 秒**。
  - BBS > 45 → TUGT 通常 < 15 秒（社区老年人正常水平）。

### 5. MAS（Modified Ashworth Scale）
- **肌张力/痉挛评定**：0, 1, 1+, 2, 3, 4（模拟数据中用 0, 0.5, 1, 1.5, 2, 3, 4 表示）。
- **临床含义**：
  - **0–1+**：轻微或无痉挛，不影响主动运动。
  - **2**：痉挛较明显，但被动活动仍容易。
  - **3–4**：痉挛严重，被动活动困难（3）或肢体僵直（4）。
- **与功能的关系**：
  - MAS 越高（尤其≥2），主动踝背屈、膝屈越受限，**FMA-LE 和 BBS 的上限被压低**，TUGT 会变慢或无法完成。
  - 康复过程中 MAS 下降（痉挛缓解）通常是 FMA-LE 和 BBS 提升的**前置条件或同步条件**。

### 6. CSS（Chinese Stroke Scale）
- **总分 0–45 分**，8 项：意识、水平凝视、面瘫、言语、步行能力、肩/手/下肢运动功能。
- **评分方向**：越高代表神经功能缺损越严重（与 NIHSS 同向）。
- **与 MAS 的耦合**：
  - CSS 中的"步行能力"和"下肢运动功能"直接受肌张力影响。
  - 当 MAS 升高（痉挛加重）时，CSS 的步行/下肢运动评分应**恶化（分数升高）**。
  - 当 MAS 降低、FMA-LE 升高时，CSS 应**改善（分数降低）**。

## 三、常识性耦合规则（非算法，用于人工/AI 校验）

### 规则 C1：TUGT 必须与 BBS、FMA-LE 同向演进
- 当 FMA-LE ↑ 且 BBS ↑ 时，TUGT 必须 ↓（缩短）或保持 N/A。
- **禁止出现**：FMA-LE 和 BBS 明显好转，但 TUGT 反而变长。
- **原因**：TUGT 与 BBS 的负相关高达 r≈-0.7，这在生物学上是稳定的。

### 规则 C2：BBS < 21 时 TUGT 必须为 N/A
- 患者连无支撑站立都做不到，不可能完成"从椅子站起、走3米、转身、坐下"的 TUGT 任务。

### 规则 C3：BBS 21–36 时 TUGT 不应过快
- BBS 在此区间代表"可站立但步态底盘不稳"。
- TUGT 如果≤35 秒，意味着步态转移已经相当流畅，与 BBS 所代表的平衡水平矛盾。

### 规则 C4：FMA-LE ≥22（分离运动大关）时的功能爆发
- 当患者从 T0 到后续时点跨越 22 分时：
  - **BBS 应有明显提升**（因为站立位单腿控制成为可能）。
  - **ADL Mobility 应有级别跨越**（从 0/5 分→10/15 分，或从轮椅→辅助步行→独立步行）。
  - **TUGT 应从 N/A 或极慢（>50s）进入可测量范围（<60s）**。
- 若 FMA-LE 跨越 22 分但 ADL 只涨了 2–3 分，这是"只见细胞改善、不见功能改善"的违和感。

### 规则 C5：FMA-LE ≥28 且 BBS ≥38 时 ADL 进入天花板
- 此时患者已具备独立步行和良好平衡，ADL 总分应≥80。
- 后续单周期 ADL 增量不应超过 5 分（此点已在硬规则 R4.3 中体现）。

### 规则 C6：MAS 与 CSS 的反向联动
- 康复有效的方向上：
  - **MAS ↓**（痉挛缓解）应伴随 **CSS ↓**（神经缺损减轻）。
  - **MAS ↑** 应伴随 **CSS ↑**。
- 禁止出现：MAS 从 1.5 降到 0.5（明显好转），但 CSS 反而从 8 升到 11（明显恶化），除非有特殊临床事件（如并发其他神经缺损）。

### 规则 C7：MAS 对 FMA-LE 和 BBS 的钳制
- 若某时点 MAS ≥2.5（即 2+ 或 3 级），则：
  - FMA-LE 很难超过 20（因为踝背屈、膝屈受痉挛限制）。
  - BBS 很难超过 36（因为站立平衡和转移受限）。
  - TUGT 很可能为 N/A 或 >45 秒。

### 规则 C8：纵向轨迹的单调性（大趋势）
- 在康复有效的组（G1、G2）中：
  - FMA-LE、BBS、ADL 的**大趋势应为上升**（允许个别时点微小平台或回落，但不应出现断崖式下降）。
  - TUGT 的**大趋势应为下降或保持 N/A**（允许微小波动，但不应在好转期明显延长）。
  - MAS、CSS 的**大趋势应为下降**。
- 在对照/无效组（G3、G4）中：
  - 上述趋势可以平缓、停滞或轻微恶化，但同样不应出现康复组才有的"暴涨"或"暴跌"。

### 规则 C9：步态三角一致性（FMA-LE ↔ BBS ↔ TUGT）
- "下肢力量 + 平衡"与"步态耗时"构成一个稳定的临床三角。
- 若其中两个明显好转，第三个必须也好转。
- 审稿人比喻：田径运动员腿力和核心稳定性变强了，百米冲刺不可能变慢。这一常识必须被尊重。

## 四、用于生成器校验的操作化检查清单

生成模拟数据后，随机抽查 20% 患者全轨迹，逐条核对：

1. [ ] 患者的 FMA-LE、BBS、ADL 同步好转时，TUGT 是否缩短？
2. [ ] 是否有 BBS<21 但 TUGT 有数值的低级错误？
3. [ ] FMA-LE 跨越 22 分时，ADL Mobility 是否有至少一个级别的提升（0→5→10→15）？
4. [ ] MAS 下降时，CSS 是否大致同向下降？
5. [ ] 同一患者内部，是否存在"神经可塑性物理极限"的突破（单周期 BBS↑>9、TUGT 缩短>15s）？
6. [ ] 康复组整体趋势是否符合"FMA↑、BBS↑、ADL↑、TUGT↓、MAS↓、CSS↓"？
