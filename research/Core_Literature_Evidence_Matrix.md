## 一、修订后的硬性约束逻辑锁（Checklist v2）

### 模块一：T0 基线特异性生理约束（发病 1 个月）

- **[R1.1] 痉挛轻中度钳制**：IF (Time == T0) THEN MAS IN {1, 1+} AND CSS IN {8, 11}
  - 🚨 **造假拦截**：IF (Time == T0) AND (MAS > 1+ OR CSS > 11) THEN REJECT
  - **理由**：发病1个月处于 Brunnstrom II→III 转化初期，UMNS 自然时间轴上痉挛刚开始显现。CSS 分级：0–9轻度，10–12中度，13–16重度。若 T0 队列平均 CSS 超过11或 MAS 达2级，违背亚急性早期真实分布。

- **[R1.2] 卒中亚型基线劣势**：Hemorrhagic_FMA-LE_T0 < Ischemic_FMA-LE_T0
  - 🚨 **造假拦截**：IF (Hemorrhagic_FMA-LE_T0 >= Ischemic_FMA-LE_T0) THEN REJECT
  - **文献状态**：基于临床共识保留，直接量化证据仍弱。

### 模块二：纵向演进与"追赶效应"（Catch-up Effect）

- **[R2.1]** Slope_Hemorrhagic(T2→T3) > Slope_Ischemic(T2→T3)
- **[R2.2]** 末期反超印证（T3）：Hemorrhagic_FMA-LE_T3 > Ischemic_FMA-LE_T3 AND Hemorrhagic_MBI_T3 > Ischemic_MBI_T3
- **[R2.3]** 步态反超印证：Hemorrhagic_TUGT_T3 < Ischemic_TUGT_T3
  - 🚨 **造假拦截**：IF (Hemorrhagic_TUGT_T3 >= Ischemic_TUGT_T3) THEN REJECT
  - **文献状态**：⚠️ **待验证假设**。当前 PubMed 检索未找到出血性 vs 缺血性纵向反超的直接文献。

### 模块三：生物力学与步态解锁（BBS ↔ TUGT 强制锁）

- **[R3.1] 绝对瘫痪红线**：IF (BBS < 21) THEN TUGT == N/A
  - 🚨 **造假拦截**：IF (BBS < 21 AND TUGT != N/A) THEN REJECT
  - **理由**：BBS < 21 表明患者连基础无支撑坐位或辅助站立都难维持，绝对无法完成3米起立行走。

- **[R3.2] 强制平衡解锁锁（步态底盘卡点）**：
  - 🚨 **造假拦截**：IF (TUGT != N/A AND BBS < 21) THEN REJECT
  - 🚨 **次级锁**：IF (BBS BETWEEN 21 AND 36) THEN TUGT 必须 > 35s
  - **理由**：BBS 21–36 分属于跌倒高危区间，患者可在辅助/监护下勉强完成 TUGT，但耗时极长（>40s）。Khan et al. (2022) 证实 BBS 是 TUG→Mobility 路径的显著中介，但 37 分作为解锁点过高。

- **[R3.3] 高质量步态三角**：
  - 🚨 **造假拦截**：IF (TUGT < 25s) AND (FMA-LE < 21 OR BBS < 38 OR MAS > 2) THEN REJECT
  - **补充锁**：在 FMA-LE 突破 18 分，其 TUGT 才有资格降至 45 秒以内。IF (FMA-LE <= 12 AND TUGT < 40s) THEN REJECT
  - **文献状态**：联动关系（快TUG↔高BBS↔高ADL）获得强支撑（r=0.81~0.925），但精确数值 21/38/25/45 仍为临床经验阈值。

### 模块四：宏观功能阶跃与天花板（FMA-LE ↔ ADL 强制锁）

- **[R4.1] 解锁前绝对滞后效应**：
  - 🚨 **造假拦截**：IF (FMA-LE < 15 AND MBI > 65) THEN REJECT
  - **文献状态**：中等。Kim 2023 入院 K-MBI=56±29，重度患者 MBI≈56 与 ≤65 间接吻合，但直接 FMA-LE<15 分层证据仍缺。

- **[R4.2] 强制阶跃锁（Jump Effect）**：
  - 🚨 **造假拦截**：IF (FMA-LE_Previous < 22 AND FMA-LE_Current >= 22) AND (单周期 ΔMBI < 6) THEN REJECT
  - **文献状态**：⚠️ **弱**。22 分作为 ADL 阶跃阈值的直接文献仍未找到。建议降级为 FLAG_REVIEW 或标注为"临床经验阈值"。

- **[R4.3] 天花板效应（Ceiling Effect）**：
  - 🚨 **造假拦截**：IF (FMA-LE >= 28 AND MBI >= 80) AND (后续单周期 ΔMBI > 5) THEN REJECT
  - **文献状态**：弱。高MBI天花板存在合理，但单周期 ΔMBI≤5 缺乏纵向文献直接验证。

### 模块五：可塑性极限钳制（Delta Max 封顶锁）

- **[R5.1] 违背神经重塑单周期（2周）物理极限**：
  - 🚨 **造假拦截**：IF (单周期 ΔFMA-LE > 8) OR (单周期 ΔBBS > 9) OR (单周期 TUGT缩短幅度 > 15s) THEN REJECT
  - **理由**：FMA-LE MCID≈6分，BBS MCID≈4–5分。即便在多模态神经调控联合机器人训练下，2周内增长超过 1.5×MCID（即8分和9分）也逾越了中枢神经轴突发芽与突触重塑的生理周期。
  - **文献状态**：MCID 数值有文献支撑，但"2周绝对上限=1.5×MCID"为基于MCID的推导假设，尚无纵向研究直接验证该精确封顶值。

## 三、核心文献数据卡片（再确认）

### 支撑 R1.1 修订的关键数据
**PMID 38162337 — Kim et al., 2023 (n=123)**
- 亚急性期入院患者下肢 MAS 分布：
  - MAS 0: 88.6%
  - MAS 1: 10.6%
  - MAS 2: 0.8%
- **结论**：原设定 MAS∈{1+,2} 会让 88.6% 的真实患者被误判为造假。修订为 MAS∈{1,1+} 并 CSS∈{8,11} 后，更符合"轻中度为主、尚未触顶"的亚急性早期分布。

### 支撑 R3.2 修订的关键数据
**PMID 36554493 — Khan et al., 2022 (n=41)**
- BBS median = 47.14 (IQR 10–56)
- RMI ↔ BBS: r = 0.81, p < 0.0001
- RMI ↔ TUG: r = -0.81, p ≤ 0.0001
- **回归**：BBS β = 0.534 (p = 0.001) 是 Mobility 最强预测因子
- **中介分析**：BBS 显著中介 TUG→RMI，indirect effect β = -0.056 (p = 0.001)
- **结论**：BBS 确实是步态/mobility 的功能底盘。但用户样本中最低 BBS 为 10 分，没有 BBS < 21 的数据。临床观察支持 21 分以下为"绝对无法完成 TUGT"的合理 cut-off。

### 支撑 R5.1 修订的 MCID 依据
- **FMA-LE MCID ≈ 6 分**（慢性/亚急性偏瘫下肢）
- **BBS MCID ≈ 4–5 分**
- **修订逻辑**：2 周极限 = 1.5 × MCID → ΔFMA-LE ≤ 8, ΔBBS ≤ 9
- **结论**：该推导在神经可塑性的生理时间轴上更严谨，避免了原 13/16 分阈值过于宽松导致的"漏过乐观造假"风险。
