# 脑卒中康复模拟数据 Skill

当用户希望为脑卒中康复研究生成、优化、审计或修订一份模拟临床数据集时，使用这个 skill。它尤其适用于重复测量数据，指标包括 FMA-LE、ADL/MBI、BBS、TUGT、MAS 和 CSS 等。

## 核心使命

你的任务是生成一份个体级合成数据，并且同时满足以下要求：
1. 符合用户设定的组水平目标均值与标准差结构；
2. 符合用户规定的临床机制约束；
3. 在纵向时间演进上具有合理性；
4. 符合输出格式要求。

**反常识铁律：绝不能把这个任务当成简单的独立正态抽样。必须始终先生成轨迹，再做审计，再对入选队列做优化。**

---

## 执行入口（两种模式）

| 模式 | 触发条件 | 行为 |
|------|----------|------|
| **快速模式** | 用户一次性明确给出：组数、每组 n、时间点、目标均值/SD 表、输出格式 | 跳过澄清，直接进入参数映射 |
| **完整模式** | 任一关键项缺失或存在歧义 | 执行第一步澄清，最多提 3 个问题 |

---

## 第一步：任务锁定（快速确认）

先用一句话简要重述用户真正想解决的问题。确认以下内容：
- 组数；
- 每组样本量；
- 时间点；
- 所需变量；
- 输出结构（长表还是宽表）；
- N/A 这样的文本状态是否必须保留为字符串。

**若无歧义，用快速模式，不反问，直接开工。**

---

## 第二步：建立结构化参数映射

把用户给出的目标表转换成机器可用的参数映射：
- `group -> metric -> timepoint -> {mean, SD}`
- 变量类型：连续型 / 有序型 / 文本门控型
- 变量之间的硬性依赖关系

常见变量类别如下：
- **连续型**：FMA-LE、ADL/MBI、BBS、CSS、数值型 TUGT
- **有序/字符串型**：MAS（输出用数字表示，例如：1+级用 1.5，2+级用 2.5，方便计算均数）
- **条件性文本变量**：在锁定状态下的 TUGT（N/A、>42、>45）

---

## 第三步：生成大规模候选池

不要直接生成最终样本量的患者。而是应该：
- 先生成一个大的候选池，通常至少是最终样本量的 8 到 20 倍；
- 为每个受试者构建跨所有时间点的完整纵向轨迹；
- 保留同一受试者内部各指标之间的依赖关系；
- 约 95% 的抽样值应落在以目标均值/标准差为中心的主体分布带内；
- 允许约 5% 的临床上合理的尾部豁免值，增加真实感。

**默认设置（除非用户覆盖）：**
- 最终样本量 ≈ 120 人 → 候选池至少 **1500 条轨迹**；
- 最终样本量 ≈ 60 人 → 候选池至少 **1000 条轨迹**。

---

## 第四步：硬性约束审计（Checklist）

审计按以下**优先级降序执行**，一旦冲突，高优先级优先：

### P0：T0 基线特异性生理约束（发病 1 个月，亚急性早期）
- `IF (Time == T0) THEN MAS IN {1, 1.5, 2} AND CSS IN {8, 13}`
- **REJECT**：T0 时 MAS > 2 或 CSS > 13

### P1：生物力学与步态锁（BBS ↔ TUGT）

| 规则 | 说明 | REJECT 条件 |
|------|------|-------------|
| R3.1 | 绝对瘫痪红线 | BBS < 21 且 TUGT != N/A |
| R3.2 | 步态底盘与耗时卡点 | 21 <= BBS <= 36 且 TUGT <= 35s |
| R3.3 | 高质量步态三角一致性 | TUGT < 25s 且 (FMA-LE < 21 或 BBS < 38 或 MAS > 2) |
| R3.4 | 下肢功能底盘 | FMA-LE <= 12 且 TUGT < 40s |

### P2：宏观功能拓扑锁（FMA-LE ↔ ADL）
- **R4.1 解锁前绝对滞后效应**：FMA-LE < 15 时，MBI 必须 <= 65
- **R4.3 天花板效应钳制**：FMA-LE >= 28 且 MBI >= 80 时，后续单周期 ΔMBI 必须 <= 5

### P3：神经可塑性极限锁（Delta Max）
- **R5.1 单周期（2 周）重塑极限钳制**：
  - 单周期 ΔFMA-LE > 8
  - 单周期 ΔBBS > 9
  - 单周期 TUGT 缩短幅度 > 15s

### P4：纵向演进真实性
- **R2.1 亚型演进轨迹**：若数据呈现无噪音的规律性反超（如所有正向指标均精准反超 0.5–1.0 分），判定为算法伪造，REJECT。

---

## 第五步：两阶段筛选与优化

### 阶段 A：硬性过滤
剔除所有违反 P0–P4 的候选轨迹。

**回退机制**：
- 若过滤后可用候选数 < 目标样本量 × 2，返回第三步，将候选池扩大至 **3000 条**。
- 若仍不足，放宽主体分布紧度（允许 ±1.5 SD 替代 ±1.0 SD），但**绝不放宽 P0–P3 硬规则**。

### 阶段 B：基于评分的筛选

在保留下来的候选数据中，设损失函数：
```text
Loss = w1 × |实际均值 - 目标均值| + w2 × |实际SD - 目标SD| + w3 × 叙事偏离分
```

默认权重：w1 = 0.5, w2 = 0.3, w3 = 0.2
若用户说“均值更重要”：w1 = 0.7, w2 = 0.15, w3 = 0.15
若用户说“SD 可以更灵活”：w2 降至 0.1，允许实际 SD 在目标 ±20% 内

从可用候选中按 Loss 最低原则逆向筛选，凑齐目标样本量。

### 优化优先级
除非用户另有说明，否则默认按以下顺序优化：
1. 零硬规则违例；
2. 组级叙事与审计逻辑正确；
3. 均值贴近；
4. SD 贴近；
5. 外观平滑。

---

## 第六步：最终审计与输出

### 交付前必查 3 项
- [ ] 零硬规则违例（抽查 20% 患者全轨迹）；
- [ ] 各组各时点实际 mean/SD 与目标偏差 <= 5%（或用户允许的阈值）；
- [ ] 文本型状态（N/A、>42、>45）未被意外转为数值。

### 主数据集输出
**默认输出长表**，表头：
```
分组 | 组别说明 | 患者ID | 卒中亚型 | 时间点 | FMA_LE | ADL | BBS | TUGT | MAS | CSS
```
- 每位患者每个时间点输出一行；
- MAS 用数字表示（1+ → 1.5），方便计算均数；
- 对文本变量必须保留原始字符串值。

### 附赠信息（必须输出在数据集下方）
- 每组每时点实际 mean / SD 对照表；
- 硬规则通过率和阶段 B 优化后的最终 Loss 摘要。
