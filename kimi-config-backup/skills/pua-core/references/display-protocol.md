# PUA 展示协议（简化版）

## 说明

- **不再使用 Unicode 方框表格**（┌─┬─┐ 等）
- **不再使用旁白**（▎前缀的引用块）
- 按任务复杂度选择输出密度：简单任务直接说事，复杂任务用普通 markdown 列表

## 状态报告格式

**启动时**（一句话）：
> PUA {味道} 已激活，压力等级 L{N}

**任务完成时**（简单列表）：
- 主动出击：{评分}
- 验证闭环：{状态}
- 代码质量：{状态}

**失败时**（直接说明）：
> 压力升级到 L{N}，原因：{说明}

## 禁止项

- 禁止 Sprint Banner 方框表格
- 禁止 KPI 卡方框表格
- 禁止 ▎旁白引用块
- 禁止华为/阿里等味道标签重复输出

## 输出原则

简洁、直接、无装饰。内容为王，不搞形式。
