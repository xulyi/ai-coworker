# thesis-data-analysis — 典型使用示例与行为规范指南

> 本文件提供本 skill 的典型输入场景、预期行为流程和输出结构规范，兼作回归测试用例的行为基准。
>
> **核心原则**：本 skill 不是"快速出统计结果"的工具，而是"先确保方法正确，再产出论文可用结果"的决策辅助系统。
>
> **判断优先级**：问题澄清 → 统计路径判定 → 前提假设验证 → 方法适用性判断 → 执行分析 → 论文化输出

---

## 示例 1：两独立组连续变量比较（标准路径）

### 用户输入
我有实验组和对照组各 30 人，想比较干预后疼痛评分的差异，请帮我分析。

### 预期行为（必须按序执行）

**阶段一：前置澄清（不可跳过）**
在分析前须向用户确认：
1. 疼痛评分是连续变量还是序数量表评分？（如 NRS 0–10 分，通常视为连续变量，需说明处理惯例）
2. 两组是完全独立的受试者，还是存在配对关系（如兄弟对、同期入组配对）？
3. 是否只比较干预后截面差异，还是同时需要比较干预前、分析"前后变化量（change score）"或"差中差（DiD）"？
4. 是否有基线差异需要控制（如采用 ANCOVA）？

**阶段二：统计路径判定**
输出统计路径判定说明：
- 研究问题类型：两独立组连续变量均值比较
- 候选方法：独立样本 t 检验 / Welch t 检验 / Mann-Whitney U 检验
- 路径选择依据：取决于正态性（Shapiro-Wilk）+ 方差齐性（Levene）+ 样本量

**阶段三：前提假设验证**
输出 Python 代码，执行：
```python
from scipy import stats
import pingouin as pg

# 正态性检验（n < 50 用 S-W）
stat_A, p_A = stats.shapiro(group_A)
stat_B, p_B = stats.shapiro(group_B)

# 方差齐性检验
levene_stat, levene_p = stats.levene(group_A, group_B)

# Q-Q 图（目视判断）
import matplotlib.pyplot as plt
fig, axes = plt.subplots(1, 2)
stats.probplot(group_A, plot=axes[0]); axes[0].set_title("Group A Q-Q")
stats.probplot(group_B, plot=axes[1]); axes[1].set_title("Group B Q-Q")
plt.tight_layout(); plt.savefig("qq_plot.png", dpi=150)
```

**阶段四：方法适用性判断与选择**
- 若两组均 p_SW > 0.05 且 p_Levene > 0.05 → 独立样本 t 检验（等方差版本）
- 若两组均 p_SW > 0.05 但 p_Levene < 0.05 → Welch t 检验（不假设方差齐性）
- 若任一组 p_SW < 0.05 → Mann-Whitney U 检验，同时说明为何不选 t 检验

**阶段五：执行分析（含效应量与 CI）**

Python 分析代码（完整版）：
```python
import numpy as np
from scipy import stats
import pingouin as pg

# 独立样本 t 检验（equal_var=True 或 False 由 Levene 决定）
result = pg.ttest(group_A, group_B, paired=False, correction='auto')
# result 包含：t 值、df、p 值、Cohen's d、95% CI、power

# Mann-Whitney U（备选）
U, p_mw = stats.mannwhitneyu(group_A, group_B, alternative='two-sided')
r_effect = abs(stats.norm.ppf(p_mw/2)) / np.sqrt(len(group_A) + len(group_B))
print(f"Mann-Whitney U={U:.3f}, p={p_mw:.4f}, r={r_effect:.3f}")
```

SPSS Syntax：
```spss
/* 独立样本 t 检验 */
T-TEST GROUPS=group(1 2)
  /MISSING=ANALYSIS
  /VARIABLES=pain_score
  /CRITERIA=CI(.95).

/* 如需 Mann-Whitney */
NPAR TESTS
  /M-W=pain_score BY group(1 2)
  /MISSING ANALYSIS.
```

**阶段六：完整输出结构**
- 前提假设检验报告（Shapiro-Wilk + Levene 结果）
- 方法选择说明及理由
- 统计结果报告（t / U，df，p，95% CI，效应量）
- 论文式结果段落（参见 result-paragraph-templates.md 第三节）
- 箱线图建议（含均值点、误差棒）
- 三线表建议：组别 | n | M±SD | t/U | p | Cohen's d [95% CI]
- 统计学方法摘要（Methods 段落）

## 示例 2：同一批患者前后比较（配对设计）

### 用户输入
我有 20 名患者治疗前后的平衡评分（Berg 平衡量表，0–56 分），想知道治疗是否有改善效果。

### 预期行为

**阶段一：澄清**
1. 确认是否为同一批患者的两次测量（配对设计）。
2. Berg 评分通常视为等距量表，可作连续变量处理，但须说明此判断的前提与惯例。
3. 是否还有对照组需要同时比较（若有则为混合设计，见示例 5）？

**阶段二：前提假设验证**
对差值（Post − Pre）进行 Shapiro-Wilk 检验，同时绘制差值直方图与 Q-Q 图。

**阶段三：方法判断树**
- 差值 p_SW > 0.05 → 配对 t 检验，效应量用 Cohen's d_z = 差值均值 / 差值标准差
- 差值 p_SW < 0.05 → Wilcoxon 符号秩检验，效应量用 r = Z/√N
- 若 n < 10，即使 SW 不显著也应优先考虑非参数方法（样本量不足以稳健判断正态性）

**阶段四：完整输出结构**
- 差值正态性检验报告
- 配对 t 检验 / Wilcoxon 结果（含效应量与 95% CI）
- 配对点图（每个受试者用线段连接前后值，直观呈现个体变化）
- 差值 Bland-Altman 图（若涉及测量一致性评估）
- 论文式结果段落（含方法替换理由）
- 统计功效计算（事后检验，1−β = ?）

## 示例 3：三组独立样本连续变量比较（多组设计）

### 用户输入
我有三组患者（对照组、低强度干预组、高强度干预组）的步速数据，想比较三组是否存在差异。

### 预期行为

**阶段一：澄清**
1. 三组是完全独立的受试者还是同一组受试者的三个条件？（若后者为重复测量设计，见示例 4）
2. 步速测量的单位与精度是什么？是否有离群值（如因辅具使用导致步速异常）？
3. 研究假设是仅检验总体差异，还是有预设的特定对比方向（如"高强度 > 低强度"）？

**阶段二：ANOVA 前提验证（三步流程）**
1. 对每组分别进行 Shapiro-Wilk 检验
2. 进行 Levene 方差齐性检验
3. 检查各组 n（每组 n ≥ 15 时中心极限定理提供一定正态性保护）

**阶段三：方法选择树**
```
正态性满足 + 方差齐性满足 → One-Way ANOVA + Tukey HSD 事后检验
正态性满足 + 方差不齐     → Welch ANOVA + Games-Howell 事后检验
正态性不满足              → Kruskal-Wallis 检验 + Dunn 检验（Bonferroni 校正）
```

**阶段四：效应量报告**
- One-Way ANOVA：η² = SS_between / SS_total；同时报告 ω²（无偏估计）
- Kruskal-Wallis：η²_H = (H − k + 1) / (n − k)
- 事后两两比较：每对报告 Cohen's d + 95% CI（不得仅报告是否显著）

**阶段五：完整输出结构**
- 前提检验报告（每组 Shapiro-Wilk + Levene 结果）
- ANOVA / Kruskal-Wallis 主效应结果
- 事后比较结果（含所有两两对比的 p_adj 与效应量）
- 箱线图 + 小提琴图（叠加独立数据点，n ≤ 50 时推荐）
- 三线表：组别 | n | M±SD 或 M[IQR] | F 或 H | p | η² 或 η²_H
- 论文式结果段落

## 示例 4：重复测量分析（多时间点设计）

### 用户输入
我有 30 名患者在康复训练前（T0）、4 周（T1）、8 周（T2）的 FIM 评分，想分析时间效应。

### 预期行为

**阶段一：澄清**
1. 只有一组受试者（单组重复测量）还是有实验组与对照组（混合设计，见示例 5）？
2. FIM 评分（18–126 分）通常视为等距连续变量处理，需说明此判断的适用条件。
3. 是否存在脱落患者（某时间点数据缺失）？脱落如何处理？

**阶段二：前提假设验证（三步）**
1. 对每个时间点分别进行 Shapiro-Wilk 检验
2. 对两两差值（T1-T0、T2-T1、T2-T0）分别检验正态性
3. 进行 Mauchly 球形假设检验（仅重复测量 ANOVA 需要）

**阶段三：方法选择树**
```
正态性满足 → 重复测量 ANOVA
  ├── Mauchly p > 0.05 → 报告原始 F 与自由度
  └── Mauchly p < 0.05 → ε < 0.75：Greenhouse-Geisser 校正
                          ε ≥ 0.75：Huynh-Feldt 校正

正态性不满足 → Friedman 检验 + Wilcoxon 符号秩事后检验（Bonferroni 校正）
```

**阶段四：效应量与事后比较**
- 重复测量 ANOVA：偏 η²（时间主效应）
- 事后两两时间点比较（T0 vs T1、T0 vs T2、T1 vs T2）：配对 t 检验 + Bonferroni 校正，每对报告 Cohen's d_z + 95% CI
- Friedman 替代方案：Kendall's W（整体效应量）；事后 Wilcoxon + Bonferroni，效应量 r

**阶段五：完整输出结构**
- 球形假设检验报告（含 ε 值与所用校正方法）
- 时间主效应结果（F / χ²，df，p，效应量）
- 事后两两比较（校正后 p 值 + 效应量 + CI，建议以表格形式呈现）
- 折线图（X 轴：时间点；Y 轴：均值 ± SE；含误差棒）
- 三线表：时间点 | n | M±SD | F / χ² | p | 偏η² / W
- 论文式结果段落（含球形假设处理说明）

## 示例 5：混合设计（组别 × 时间交互分析）

### 用户输入
我有实验组（n=25）和对照组（n=25）各在基线、4 周、8 周三个时间点测量了步行速度，想分析干预效果。

### 预期行为

**阶段一：澄清**
1. 确认两组受试者完全独立（非配对），且每位受试者均有 3 个时间点的数据。
2. 研究假设是"干预使步速提升更多（交互效应）"，还是"干预后两组均有提升（时间主效应）"？
3. 是否有脱落？采用何种缺失值策略（完全病例分析 / 多重插补 / 混合线性模型）？

**阶段二：分析框架判断**
- 主分析：2（组别：实验 vs 对照）× 3（时间：T0, T1, T2）混合方差分析
- 关注焦点：**组别 × 时间交互效应**（这是干预有效性的核心检验）
- 若有较多缺失（> 10%）：考虑以线性混合效应模型（LMM）替代，可处理不等间距时间点与缺失数据

**阶段三：前提假设验证**
- 各组各时间点正态性（Shapiro-Wilk）
- 各时间点 Levene 方差齐性检验
- 球形假设检验（Mauchly，针对组内因子）

**阶段四：完整输出结构**
- 交互效应结果（F，偏η²，p）——**优先报告，是干预有效性的核心证据**
- [交互显著时]：简单效应分析
  - 各组内：时间效应（T0→T1→T2 变化）+ Bonferroni 校正事后比较 + Cohen's d_z
  - 各时间点上：组间差异 + Cohen's d
- [交互不显著时]：报告时间主效应与组别主效应，明确说明"无组间差异化反应"的含义与局限性
- 交互效应图（折线图，双组双线，含 SE 误差棒）
- 三线表：时间点 | 实验组 M±SD | 对照组 M±SD | 交互 F | p | 偏η²
- 论文式结果段落（包含交互效应解读）

## 示例 6：分类变量组间比较（卡方 / Fisher）

### 用户输入
我想比较实验组和对照组的不良事件发生率（有 / 无）是否存在差异。

### 预期行为

**阶段一：澄清**
1. 不良事件是单一二分类结果，还是多类别结果（如 0 次、1 次、≥ 2 次）？
2. 样本量预估：若两组各约 30 人，不良事件发生率估计约为多少？（预判期望频数是否满足卡方条件）
3. 两组受试者是否独立？（若为配对设计则需 McNemar 检验）

**阶段二：方法选择判断**
```
期望频数检验规则：
  所有格子期望频数 ≥ 5                          → 卡方检验（Pearson χ²）
  < 20% 格子期望频数 < 5，且最小期望频数 ≥ 1    → 卡方检验（可接受）或 Fisher 精确检验
  任意格子期望频数 < 1，或 > 20% 格子期望 < 5   → Fisher 精确检验（强制）
  配对数据（前后 / 同一受试者两种测量）         → McNemar 检验
```

**阶段三：效应量与 CI 报告**
- 卡方检验：Cramér's V（2×2 时等于 φ）
- Fisher 精确检验：OR（优势比）+ 95% CI（精确法 Cornfield 区间）
- 临床语境中同时报告：RR（相对风险）和 NNT（需治疗数）

**阶段四：完整输出结构**
- 列联表（含各格子实际频数与期望频数）
- 适用性判断说明（期望频数检查结果）
- 卡方 / Fisher 检验结果（χ²，df，p，OR，95% CI）
- 两组发生率的 95% CI（Wilson 区间法，适用于小样本）
- 论文式结果段落
- SPSS Syntax + Python 重算代码

## 示例 7：用户指定了错误或不适合的方法

### 用户输入
我有两组偏态分布的疼痛评分数据，帮我做 t 检验。

### 预期行为（禁止直接执行用户指令）

**阶段一：不执行，先做方法适用性判断**

首先说明：用户指定的方法需在满足前提假设的条件下才适用，本 skill 必须先完成判断再决定是否执行。

**阶段二：输出判断过程**
- 独立样本 t 检验的核心前提：① 两组数据近似正态分布；② 方差齐性（等方差版本）
- 用户已描述数据为"偏态分布"，直接违反前提假设 ①
- 量化判断：用 Shapiro-Wilk 或偏度/峰度系数确认偏态程度

**阶段三：提供替代方案（按优先级排列）**
1. **首选**：Mann-Whitney U 检验（不依赖正态性假设，适用于偏态连续变量）
2. **次选**：若 n ≥ 30（每组），中心极限定理提供一定保护，可在说明局限性前提下谨慎使用 Welch t 检验
3. **数据变换选项**：若偏态由特定原因导致（如严重右偏），可尝试对数变换后重新检验正态性，再决定

**阶段四：用户坚持要 t 检验时的处理**
若用户在知悉上述分析后仍坚持使用 t 检验，则：
1. 执行 t 检验（尊重用户最终决定权）
2. 在输出中**明确标注风险警告**：
   > ⚠️ 方法风险提醒：当前数据分布不满足 t 检验正态性前提（S-W p = [值]），t 检验结果可能不可靠。强烈建议同时报告 Mann-Whitney U 检验结果作为稳健性参照，并在论文局限性中说明此问题。
3. 自动同步输出 Mann-Whitney U 检验结果供对比

## 示例 8：只有 SPSS 输出截图，无原始数据

### 用户输入
这是我的 SPSS 输出结果（截图），你帮我解释一下，并用 Python 验证。

### 预期行为

**阶段一：明确当前能做和不能做的事**

✅ 能做：
- 解读 SPSS 输出表格中的统计量（t、F、p、df、均值、标准差等）
- 核查报告格式是否符合 APA 7th 规范
- 指出常见误读（如 SPSS 显示 .000 应报告为 < .001）
- 识别检验类型并给出对应的结果段落写法建议

❌ 不能做：
- 在没有原始数据的情况下进行 Python 完整重算
- 确认正态性假设是否满足（截图中如无 Shapiro-Wilk 输出）
- 重新进行事后多重比较（无原始数据）

**阶段二：SPSS 输出解读模板**

根据截图依次输出：
1. **检验类型识别**：识别是哪类分析（独立 t / 配对 t / ANOVA / 相关 / 回归）
2. **关键统计量提取**：从输出表格中提取 t / F / U / χ²、df、p 值、均值、SD 等
3. **结果解读**：以"论文可用"语言陈述统计结论
4. **常见误读提醒**：
   - "Sig. = .000" → 应报告为 p < .001，不得写 p = 0 或 p = .000
   - SPSS 独立样本 t 检验默认输出两行（等方差 / 不等方差），需先看 Levene 检验决定读哪行
   - ANOVA 的 F 值需同时报告两个自由度（df_between, df_within）
   - 相关分析中 r 需同时报告样本量 n 或自由度 df = n-2

**阶段三：告知用户继续验证所需的数据**

如需 Python 交叉验证，请提供：
- 原始数据文件（CSV / Excel），包含各组数据列
- 分组变量名称与编码方式（如 group: 1=实验组, 2=对照组）
- 若为重复测量：每个受试者的 ID 列与时间标识列

## 示例 9：论文式统计学方法摘要写作

### 用户输入
请根据我这份数据和分析结果，帮我写论文里的统计学分析方法部分。

### 预期行为

**阶段一：信息采集（对照 statistical-methods-summary-template.md 核查清单）**

先核对用户提供的信息是否覆盖以下要素，不足时提问：
- 研究类型与分组结构（RCT / 观察性 / 其他）
- 各变量分布特征（是否已完成正态性检验）
- 实际使用的软件及版本（切勿臆造）
- 是否进行了多重比较校正
- 缺失值与异常值处理方式

**阶段二：输出格式（严格按以下结构，不得跳过任何已知信息）**

```
【统计学分析方法】

[软件说明段]
本研究采用 [软件A（版本）] 进行统计分析，并使用 [软件B / Python库] 对主要结果进行独立交叉验证。

[数据质量处理段]
分析前对所有连续变量采用 [Shapiro-Wilk / KS] 检验评估正态性，方差齐性采用 Levene 检验评估。
[缺失值处理说明] [异常值处理说明]

[变量呈现段]
连续变量符合近似正态分布时采用均值 ± 标准差（M±SD）表示；分布偏态时采用
```

- 判断统计路径与方法适用性（包括前提假设验证）

- 在用户未提供原始数据时假装完成了 Python 重算
- 跳过前提假设验证直接执行统计检验
