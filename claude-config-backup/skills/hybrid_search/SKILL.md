# Hybrid Search Skill

双源权威搜索：Tavily MCP + WebSearch 自动整合
适用于所有 Claude Code 项目

## 触发条件

### 显式命令（直接触发）
- `@hybrid_search <查询内容>`
- `@搜索 <查询内容>`
- `/search <查询内容>`

### 自然语言触发（智能识别）
当用户输入包含以下模式时，自动识别为搜索请求：

**中文模式：**
- 搜索/查找/查询/检索 + 主题（"搜索阿尔茨海默病最新治疗"）
- 查一下/找一下/搜一下 + 主题（"查一下张明教授"）
- 帮我搜索/帮我查/帮我找 + 主题（"帮我搜索2024年GDP数据"）
- 关于...的信息/资料/情况（"关于脑卒中康复的最新研究"）
- ...怎么样/如何（"徐乐义康复水平如何"）
- 什么是.../什么是...（"什么是镜像疗法"）
- ...的背景/履历/简介（"张三的学术背景"）
- 最新/最近/今年 + 领域 + 进展/动态/消息（"最新人工智能进展"）

**英文模式：**
- Search for / Look up / Find information about...
- What is / How does / Tell me about...
- Latest news on / Recent developments in...
- Who is / Background of...
- Information about...

**学术/权威搜索信号词：**
- 论文/研究/综述/文献/期刊/发表
- 官方/权威/政府/报告/数据
- 专家/教授/博士/学者
- 最新/最近/2024/2025

**注意：** 当查询涉及隐私（个人电话、住址）或需要实时性极强（股价、比分）时，谨慎触发

## 执行流程

### Step 1: 并行双源搜索
同时调用两个搜索源（零 API Key 配置）：
1. **Tavily MCP** - 结构化来源（论文/新闻/网页）
2. **WebSearch** - 实时全网搜索

### Step 2: 结果标准化
将两源结果统一为结构化格式：
```
- title: 标题
- url: 链接
- content: 摘要/内容
- source: tavily | websearch
- authority_tier: 1|2|3 (自动判定)
- published_date: 发布时间（提取）
```

### Step 3: 权威分级（自动）
| 等级 | 来源类型 | 权重 |
|------|----------|------|
| T1 (⭐⭐⭐) | 政府(.gov)、顶级期刊(Nature/Science/Cell/Lancet/NEJM)、国际组织(WHO/World Bank/UN) | 最高 |
| T2 (⭐⭐) | 权威媒体(Reuters/Bloomberg/新华社/人民日报)、知名智库(Brookings/PIIE)、高校(.edu/.ac.uk) | 中高 |
| T3 (⭐) | 一般媒体、商业网站、博客、论坛 | 普通 |

### Step 4: 智能去重
- URL 精确匹配去重（忽略参数）
- 标题相似度去重（子串匹配，忽略大小写）
- 内容指纹去重（前100字符哈希）
- 双源交叉验证标记

### Step 5: 输出格式
```markdown
## 🔍 搜索整合结果

### 📊 来源统计
- 总计：X 条（Tavily: Y, WebSearch: Z）
- 权威分布：⭐⭐⭐ T1: A条 | ⭐⭐ T2: B条 | ⭐ T3: C条
- 交叉验证：N 条（两源同时出现）

### ⭐⭐⭐ 权威来源（政府/顶刊/国际组织）
1. **[标题]** [来源标签]
   📎 URL
   📝 摘要（200字）
   📅 年份/时间

### ⭐⭐ 可靠来源（权威媒体/智库/高校）
...

### ⭐ 其他来源（一般参考）
...

### 📋 综合分析
基于上述来源的关键发现总结（3-5点）

### ⚠️ 来源说明
- 结果已去重，保留最高权威等级版本
- ✅ 标记表示双源交叉验证
- 时间优先：2023-2025 年内容权重更高
```

## 自然语言查询提取

当用户使用自然语言而非显式命令时，按以下规则提取搜索查询：

### 提取规则
1. **去除礼貌用语**：删除"请"、"帮我"、"麻烦"、"能不能"等
2. **去除动词前缀**：删除"搜索"、"查一下"、"找一下"等触发词，保留核心查询
3. **保留完整意图**：
   - "帮我查一下徐乐义的康复水平" → "徐乐义 康复水平"
   - "关于阿尔茨海默病的最新治疗" → "阿尔茨海默病 最新治疗"
   - "什么是镜像疗法" → "镜像疗法"

### 查询优化
提取后自动优化：
- 添加时间限定（如包含"最新"自动添加 2024/2025）
- 添加权威来源限定（如学术查询自动添加顶刊站点）
- 人物查询添加"简介/履历/学术背景"

## 特殊处理规则

### 学术查询优化
当查询包含以下关键词时，Tavily 启用学术模式：
- 论文/研究/综述/meta分析/系统评价
- 期刊/影响因子/SCI/核心期刊
- 临床/病例/随机对照/RCT
- 疾病名称 + 治疗/诊断/预后/指南

### 时效性查询优化
当查询包含以下时间词时，优先最新结果：
- 2024/2025/今年/最新/最近
- 今天/昨天/本周/本月/近一年

### 中文/英文自适应
- 中文查询：两源均用中文搜索
- 英文查询：两源均用英文搜索
- 混合查询：中英文并行搜索后整合

### 人物查询优化
搜索人物时，额外关注：
- 高校官网师资页面
- 医院官网科室介绍
- 学术论文作者信息
- 政府科研项目立项
- 新闻报道（交叉验证）

**执行**: 直接执行双源搜索

### 自然语言触发
**用户**: "徐乐义这个人康复水平如何"

**识别**: 模式匹配「...怎么样」→ 提取查询「徐乐义 康复水平」

**用户**: "帮我查一下张明教授的最新研究"

**识别**: 模式匹配「帮我查一下」→ 提取查询「张明教授 最新研究」
**执行**: 搜索学术论文 + 科研项目

**用户**: "关于脑卒中康复的最新指南"

**识别**: 模式匹配「关于...的」→ 提取查询「脑卒中康复 最新指南」

**用户**: "什么是镜像疗法"

### 执行流程（通用）
1. 提取核心查询词

4. 整合去重 → 权威分级 → 交叉验证标记 → 输出

**输出结构**:
```

- 交叉验证：3 条

### ⭐⭐⭐ 权威来源
...
```

## 错误处理

| 场景 | 处理策略 |
|------|----------|
| Tavily 超时 | 降级为纯 WebSearch，提示用户 |
| WebSearch 受限 | 降级为纯 Tavily，提示用户 |
| 双源均失败 | 返回错误，建议检查网络或换查询词 |
| 结果为空 | 建议扩大关键词、改用英文或换时间范围 |

## 输出要求

1. **先给框架**：来源统计 → 权威分级列表 → 综合分析
2. **标注来源**：每条结果标注 [tavily] 或 [websearch]
3. **交叉验证**：两源均出现的内容标注"✅ 双源验证"
4. **缺失提示**：信息不足处标注"[待验证]"或"[信息缺口]"
5. **拒绝猜测**：无来源支撑时不编造信息，如实标注不确定
6. **时间戳**：标注搜索执行时间

## 边界限制

- ❌ 不执行侵犯隐私的搜索（个人电话/住址/身份证号）
- ❌ 不提供医疗/法律/投资建议，仅整理公开信息
- ❌ 不保证实时性，标注"截至搜索时间"
- ❌ 不处理需要付费墙访问的完整论文内容
