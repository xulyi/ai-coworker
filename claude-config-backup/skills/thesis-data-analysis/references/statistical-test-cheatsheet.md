# Statistical Test Cheatsheet — 统计方法选择完整决策指南

> **本文件用途**：帮助模型在面对任意研究问题时，系统性地完成"研究问题 → 变量类型 → 样本结构 → 前提验证 → 方法选择 → 效应量报告"的完整决策链。
>
> **使用铁律**：
> 1. 永远先问清研究设计和变量类型，再谈方法
> 2. 永远先验证前提假设，再执行检验
> 3. 前提不满足时，给替代方案，不强行执行参数检验
> 4. 任何差异比较结果必须同时报告效应量和 95% CI
> 5. 统计显著性 ≠ 临床意义，两者必须分别讨论

---

## 一、前置信息采集：必须回答的 10 个问题

在选择任何统计方法之前，必须明确以下信息：

| # | 核心问题 | 关键选项 |
|---|---|---|
| Q1 | 研究目的是什么？ | 差异比较 / 前后变化 / 相关性 / 预测 / 一致性 / 描述 |
| Q2 | 因变量（结局变量）是什么？ | 名称、测量单位、量表范围 |
| Q3 | 因变量的测量尺度是什么？ | 连续变量 / 等级变量 / 二分类 / 多分类 / 计数 |
| Q4 | 自变量 / 分组变量是什么？ | 类型、组别数量、编码方式 |
| Q5 | 样本之间的关系是什么？ | 完全独立 / 配对（一一对应）/ 重复测量（同一受试者） |
| Q6 | 有几个组？几个时间点？ | 2组 / 3组及以上 / 2时间点 / 3+时间点 |
| Q7 | 数据分布特征如何？ | 正态 / 偏态 / 双峰 / 极端离群值 |
| Q8 | 各组样本量是多少？ | 总 N、各组 n，是否平衡 |
| Q9 | 是否存在缺失值或异常值？ | 缺失比例、缺失模式、异常值识别方式 |
| Q10 | 是否需要控制混杂变量？ | 协变量列表、是否做调整分析 |

## 二、总体决策树（核心导航）

```
研究问题
│
├── 差异比较
│   ├── 连续变量
│   │   ├── 独立样本
│   │   │   ├── 2组 ──→ [路径A] t检验家族
│   │   │   └── 3+组 ──→ [路径B] ANOVA家族
│   │   └── 配对/重复测量
│   │       ├── 2时间点 ──→ [路径C] 配对t/Wilcoxon
│   │       ├── 3+时间点（单组）──→ [路径D] 重复测量ANOVA/Friedman
│   │       └── 组别×时间 ──→ [路径E] 混合ANOVA/LMM
│   └── 分类变量
│       ├── 独立样本 ──→ [路径F] 卡方/Fisher
│       └── 配对样本 ──→ [路径G] McNemar
│
├── 相关性分析 ──→ [路径H] Pearson/Spearman/Kendall/ICC
│
├── 预测/影响因素
│   ├── 连续因变量 ──→ [路径I] 线性回归
│   └── 分类因变量 ──→ [路径J] Logistic回归
│
└── 一致性/信度 ──→ [路径K] ICC/Kappa
```

## 三、路径 A：两独立组连续变量比较

### 前提假设验证（必须按序执行）

| 步骤 | 检验内容 | 方法 | 判断标准 |
|---|---|---|---|
| Step 1 | 各组正态性 | Shapiro-Wilk（n<50）/ KS检验（n≥50）+ Q-Q图 | p > 0.05 视为近似正态 |
| Step 2 | 方差齐性 | Levene 检验 | p > 0.05 视为方差齐 |
| Step 3 | 离群值检查 | 箱线图 / Grubbs检验 / ±3SD | 极端离群值影响t检验稳健性 |

### 方法选择

```
正态性满足 + 方差齐性满足 → 独立样本 t 检验（等方差）
正态性满足 + 方差不齐     → Welch t 检验（自动调整df）
正态性不满足（任一组）     → Mann-Whitney U 检验
样本量极小（每组 n < 5）   → 谨慎使用任何检验，优先描述性统计
```

### 效应量报告

| 方法 | 效应量指标 | 计算方式 | 解释标准 |
|---|---|---|---|
| t检验（等方差）| Cohen's d | (M1-M2) / SDpooled | 小=0.2, 中=0.5, 大=0.8 |
| Welch t检验 | Cohen's d | (M1-M2) / SDpooled | 同上 |
| Mann-Whitney U | r | Z / √N | 小=0.1, 中=0.3, 大=0.5 |

### 必须同时报告
- 两组描述统计（M±SD 或 M[IQR]）
- 统计量 + df + p 值（精确到3位小数）
- 效应量 + 95% CI
- 前提检验结果（Shapiro-Wilk W值 + p；Levene F值 + p）

## 四、路径 B：三组及以上独立组连续变量比较

### 前提假设验证

| 步骤 | 检验内容 | 方法 | 备注 |
|---|---|---|---|
| Step 1 | 每组正态性 | Shapiro-Wilk（每组分别检验）| 所有组均需满足 |
| Step 2 | 方差齐性 | Levene 检验（一次检验所有组）| |
| Step 3 | 离群值 | 各组箱线图 | |

### 方法选择

```
正态满足 + 方差齐 → One-Way ANOVA + Tukey HSD 事后检验
正态满足 + 方差不齐 → Welch ANOVA + Games-Howell 事后检验
正态不满足         → Kruskal-Wallis 检验 + Dunn 检验（Bonferroni校正）
有预设对比方向     → 计划对比（Planned Contrasts），不做事后检验
```

### 事后检验选择依据

| 情境 | 推荐事后检验 | 理由 |
|---|---|---|
| 方差齐、各组n相等 | Tukey HSD | 最常用，控制familywise错误率 |
| 方差齐、各组n不等 | Tukey-Kramer | Tukey的不等样本版本 |
| 方差不齐 | Games-Howell | 不假设方差齐性 |
| 非参数（Kruskal-Wallis显著后）| Dunn + Bonferroni | 最稳健 |
| 有特定比较假设 | Bonferroni / Holm | 控制指定比较的错误率 |

### 效应量报告

| 方法 | 效应量 | 计算 | 解释 |
|---|---|---|---|
| ANOVA | η²（Eta²）| SS_between/SS_total | 小=0.01, 中=0.06, 大=0.14 |
| ANOVA | ω²（无偏）| (SS_b - df_b×MS_w)/(SS_t + MS_w) | 比η²更保守，适合小样本 |
| Welch ANOVA | ω² | 同上 | |
| Kruskal-Wallis | η²_H | (H-k+1)/(n-k) | 小=0.01, 中=0.06, 大=0.14 |
| 事后两两对比 | Cohen's d | 各对之间单独计算 | 每对必须报告 |

## 五、路径 C：两配对组连续变量比较（前后 / 配对设计）

### 前提假设验证
对**差值**（Post − Pre）进行正态性检验，而非分别对两组检验。

```
差值 Shapiro-Wilk p > 0.05 → 配对 t 检验
差值 Shapiro-Wilk p < 0.05 → Wilcoxon 符号秩检验
每组 n < 10              → 即使SW不显著，也优先考虑Wilcoxon（样本量不足以稳健判断正态性）
```

### 效应量报告

| 方法 | 效应量 | 计算 | 注意 |
|---|---|---|---|
| 配对 t | Cohen's d_z | 差值均值 / 差值SD | 不要用 d_s（两组SD的池化），应用 d_z |
| Wilcoxon | r | Z / √N | N为参与检验的非零差值对数 |

## 六、路径 D：多时间点重复测量（单组）

### 前提假设验证

| 步骤 | 检验 | 工具 | 备注 |
|---|---|---|---|
| 正态性 | 各时间点 Shapiro-Wilk | 每个时间点分别检验 | |
| 球形假设 | Mauchly 检验 | 仅重复测量ANOVA需要 | 2个时间点时自动满足 |
| 球形违反时 | Greenhouse-Geisser 或 Huynh-Feldt 校正 | ε < 0.75 用GG；ε ≥ 0.75 用HF | 报告ε值 |

### 方法选择

```
正态满足 → 重复测量 ANOVA（含球形假设处理）
正态不满足 → Friedman 检验 + Wilcoxon 事后（Bonferroni校正）
```

### 效应量

| 方法 | 效应量 | 解释 |
|---|---|---|
| 重复测量ANOVA | 偏 η²（Partial Eta²）| 小=0.01, 中=0.06, 大=0.14 |
| Friedman | Kendall's W | 0-1范围，越大一致性越高 |
| 事后配对比较 | Cohen's d_z | 每对时间点单独报告 |

---

## 七、路径 E：混合设计（组别 × 时间）

### 核心报告顺序（重要：不得颠倒）

```
① 交互效应（组别 × 时间）→ 这是干预效果的核心检验，必须优先报告
② 若交互显著 → 简单效应分析（各组内时间效应 + 各时间点组间差异）
③ 若交互不显著 → 报告时间主效应 + 组别主效应，并说明含义
```

### 前提假设

同路径D（球形假设针对组内因子），加之：
- 各组间正态性
- 各时间点方差齐性（Levene）

### 缺失数据处理

| 缺失比例 | 处理策略 |
|---|---|
| < 5% | 完全病例分析（须在局限性中说明） |
| 5%–15% | 多重插补（MI，m ≥ 5）或 FIML |
| > 15% | 考虑线性混合效应模型（LMM），可处理不等间距与缺失 |

### 效应量
- 所有效应（主效应 + 交互）均报告偏 η²
- 简单效应中的两两对比报告 Cohen's d + 95% CI

## 八、路径 F：独立样本分类变量比较（卡方 / Fisher）

### 适用条件判断（严格按顺序）

```
Step 1: 确认两个变量均为分类变量（名义或有序）
Step 2: 确认独立样本（非配对 → 否则用McNemar）
Step 3: 检查期望频数
  所有格子期望频数 ≥ 5                   → Pearson 卡方检验
  < 20%的格子期望频数 < 5，最小值 ≥ 1    → 卡方检验（可接受，报告实际频数）
  任意格子期望频数 < 1 / > 20%格子 < 5   → Fisher 精确检验（强制）
  2×2 表且 n < 40                        → Fisher 精确检验（优先）
```

### 效应量报告

| 方法 | 效应量 | 计算公式 | 标准 |
|---|---|---|---|
| 卡方（2×2）| φ（Phi）| √(χ²/N) | 小=0.1, 中=0.3, 大=0.5 |
| 卡方（r×c）| Cramér's V | √(χ²/(N×min(r-1,c-1))) | 同上 |
| Fisher精确检验 | OR（优势比）| 精确法 | 同时报告95% CI |
| 临床场景 | RR + NNT | 相对风险 + 需治疗数 | 根据需要补充 |

---

## 九、路径 G：配对分类变量比较

```
同一受试者前后的二分类结果对比 → McNemar 检验
多分类配对结果对比              → Bowker 检验（McNemar对称性的推广）
效应量                          → OR 或 一致率差值
```

## 十、路径 H：相关分析

### 方法选择

| 条件 | 推荐方法 | 效应量 / 指标 |
|---|---|---|
| 两个连续变量，均近似正态，线性关系 | Pearson r | r² = 决定系数 |
| 任一变量偏态 / 非正态 | Spearman ρ | ρ（解释同r）|
| 等级变量或小样本（n < 20）| Kendall τ | τ（比ρ更保守）|
| 测量工具信度 / 一致性 | ICC（双因素混合效应绝对一致性）| Koo&Mae(2016)标准 |
| 两个连续变量的一致性（Bland-Altman）| Bland-Altman 分析 | 均值差 + 一致性界限 |

### 相关强度解释（Cohen, 1988）

| |r| / |ρ| 范围 | 强度解释 |
|---|---|
| 0.10–0.29 | 弱相关 |
| 0.30–0.49 | 中等相关 |
| ≥ 0.50 | 强相关 |

### 注意事项

- 相关系数必须同时报告样本量 n 或自由度 df = n-2
- 必须报告 95% CI（Bootstrap法 或 Fisher's z 变换）
- 永远不能用相关分析推断因果关系
- 相关显著但 r 很小时（如 r = 0.15, p < 0.001），注意区分统计显著与实际意义

## 十一、路径 I：回归分析（连续因变量）

### 模型类型选择

| 情境 | 模型 | 效应量 |
|---|---|---|
| 1个连续预测变量 | 简单线性回归 | R², f² |
| 多个预测变量 | 多元线性回归 | 调整R², f² |
| 控制协变量后检验主效应 | ANCOVA（协方差分析）| 偏η² |
| 预测变量为分类变量 | 设置哑变量（dummy coding）| 各系数的 95% CI |

### 回归诊断（不可省略）

| 诊断项目 | 指标 | 问题阈值 |
|---|---|---|
| 多重共线性 | VIF | VIF > 10（严重），> 5（需注意）|
| 影响性观测值 | Cook's D | > 4/n 或 > 1（严重）|
| 残差正态性 | 残差 Q-Q 图 + Shapiro-Wilk | 视觉判断 + p < 0.05 |
| 方差齐性（残差）| 残差 vs 拟合值散点图 | 无明显喇叭形扩散 |
| 独立性 | Durbin-Watson | 接近2为理想 |

### 必须报告
- B（非标准化系数）+ SE + β（标准化系数）+ t + p + 95% CI
- R² 和调整后 R² + 模型整体 F 检验
- 回归诊断结论

## 十二、路径 J：回归分析（分类因变量）

| 因变量类型 | 推荐方法 | 效应量 |
|---|---|---|
| 二分类（是/否）| Binary Logistic 回归 | OR + 95% CI；Nagelkerke R²；AUC |
| 多分类（无序）| Multinomial Logistic 回归 | OR（各类别 vs 参照类）|
| 多分类（有序）| Ordinal Logistic 回归（比例风险模型）| OR + 平行性检验 |
| 时间-事件数据 | Cox 比例风险回归 | HR（风险比）+ 95% CI |

### Logistic 回归必须报告
- OR + 95% CI（每个预测变量）
- Wald χ² + p 值
- Hosmer-Lemeshow 拟合优度检验
- Nagelkerke R²（伪 R²）
- ROC曲线 + AUC（二分类时）

## 十三、路径 K：信度与一致性分析

### 方法选择

| 情境 | 方法 | 输出指标 |
|---|---|---|
| 连续变量的评估者间信度 | ICC（双因素绝对一致性）| ICC + 95% CI |
| 连续变量的重测信度 | ICC（双因素一致性）| ICC + 95% CI |
| 二分类变量的一致性 | Cohen's Kappa | κ + 95% CI |
| 多分类变量的一致性 | Weighted Kappa | κ_w + 95% CI |
| 量表内部一致性 | Cronbach's α | α（> 0.7 为可接受）|

### ICC 解释标准（Koo & Mae, 2016）

| ICC 值 | 一致性等级 |
|---|---|
| < 0.50 | 差（Poor）|
| 0.50–0.75 | 中等（Moderate）|
| 0.75–0.90 | 良好（Good）|
| > 0.90 | 极好（Excellent）|

## 十四、ANCOVA（协方差分析）专项说明

ANCOVA 用于在控制协变量（如基线值）的前提下比较组间差异，适用场景：
- 基线不均衡的 RCT（以基线为协变量）
- 需控制人口学特征（年龄、性别等）的比较

### 前提假设（额外要求）

```
1. 协变量与因变量之间存在线性关系（各组内分别检验）
2. 回归斜率同质性（组别 × 协变量 交互项不显著）→ 若违反，ANCOVA不适用
3. 各组内因变量的残差满足正态性
```

### 效应量
- 偏 η²（Partial Eta²）

## 十五、多重比较校正策略

| 策略 | 适用情境 | 保守程度 | 说明 |
|---|---|---|---|
| Bonferroni | 少量预设比较（k ≤ 5）| 最保守 | α' = α/k |
| Holm（序贯Bonferroni）| 中等数量比较 | 较保守 | 比Bonferroni统计效能稍高 |
| Benjamini-Hochberg FDR | 大量比较（探索性研究）| 相对宽松 | 控制假发现率而非familywise错误率 |
| Tukey HSD | ANOVA事后全因比较 | 中等 | 专为成对比较设计 |
| Games-Howell | 方差不齐时ANOVA事后 | 中等 | 不假设方差齐性 |
| Dunnet | 多个实验组 vs 单一对照组 | 中等 | 效能高于Bonferroni |

## 十六、描述性统计呈现规范

| 变量分布 | 呈现方式 | 补充说明 |
|---|---|---|
| 连续变量（近似正态）| M ± SD | 同时报告 [Min, Max] 或 [95% CI] |
| 连续变量（偏态）| M [IQR: Q1, Q3] | 同时报告 [Min, Max] |
| 二分类变量 | n (%) | 说明分母（各组n 还是总N）|
| 多分类变量 | 各类别 n (%) | 百分比之和应为100% |
| 计数资料（率）| n/N (%) 或 率/1000 | 说明观察单位 |

## 十八、高风险情境识别与处理

以下任一情境出现时，**禁止直接给出正式统计推断**，必须先澄清或说明局限性：

| 高风险情境 | 处理方式 |
|---|---|
| 研究设计不清（独立？配对？）| 先提问，明确后再判断 |
| 变量类型不清（连续？等级？）| 先提问，说明不同假设下的方法差异 |
| 每组 n < 5 | 仅做描述性统计，明确说明样本量不足以进行推断 |
| 缺失比例 > 20% | 说明完全病例分析的偏倚风险，建议多重插补 |
| 分布严重偏态 + 小样本（n < 15）| 非参数方法，且结果需谨慎解读 |
| 用户指定方法与数据不匹配 | 先纠偏，给出理由，再给替代方案 |
| 只有截图、没有原始数据 | 只能解读，明确说明无法完成Python重算 |
| 极端不平衡分组（如 n1=5, n2=50）| 提醒功效与置信区间宽度的问题 |
| 多个结局变量未校正 | 必须提醒多重比较校正的必要性 |
| 将相关分析的结论表述为因果 | 立即纠正，说明相关≠因果 |

## 二十、常见错误汇总（必须避免）

| 错误类型 | 典型表现 | 正确做法 |
|---|---|---|
| 跳过前提验证 | 直接跑t检验/ANOVA，不检验正态性 | 先验证前提，再选方法 |
| 混淆样本结构 | 把配对样本当独立样本分析 | 先确认每个受试者的数据对应关系 |
| 效应量缺失 | 只报告p值，不报告效应量 | 每个检验必须同时报告效应量+CI |
| 错误效应量 | 配对设计用 d_s 而非 d_z | 配对设计必须用差值计算效应量 |
| 事后检验缺失 | ANOVA显著后不做事后比较 | 总体F显著时必须进行事后两两比较 |
| 多重比较未校正 | 同时做5个t检验，不校正 | 多重比较必须说明校正策略 |
| 因果推断 | 相关显著就说"X导致Y" | 明确说明"相关不代表因果" |
| p值误报 | 写 p=0.000 | 应写 p < .001 |
| 临床意义混淆 | p<0.05就说"临床有效" | 统计显著性与临床意义必须分别讨论 |
| 非参数结果遗漏 | 非参数检验不报告效应量 | Mann-Whitney U报告r；Wilcoxon报告r；KW报告η²_H |
