## 四、按研究类型的模板

### 1. 两独立组比较

本研究包含 [实验组名称] 与 [对照组名称] 两组受试者。连续变量若符合近似正态分布，采用均值 ± 标准差表示，并采用独立样本 t 检验进行组间比较；若方差不齐，则采用 Welch t 检验；若分布明显偏态，则采用 Mann–Whitney U 检验。分类变量采用例数和百分比表示，并采用卡方检验或 Fisher 精确检验进行比较。所有检验均为双侧检验，以 p < 0.05 为差异有统计学意义。

### 2. 配对前后比较

对于同一批受试者干预前后数据，连续变量若符合近似正态分布，采用配对 t 检验进行比较；若不满足参数检验前提，则采用 Wilcoxon 符号秩检验。分类变量如涉及配对比较，可采用 McNemar 检验。所有检验均为双侧检验，以 p < 0.05 为差异有统计学意义。

### 3. 三组及以上独立组比较

对于三组及以上独立样本的连续变量比较，若满足参数检验前提，则采用单因素方差分析；若总体差异有统计学意义，再进行事后两两比较。若不满足参数检验前提，则采用 Kruskal–Wallis 检验。分类变量采用卡方检验或 Fisher 精确检验。所有检验均为双侧检验，以 p < 0.05 为差异有统计学意义。

### 4. 重复测量数据

对于同一受试者在多个时间点的重复测量数据，若满足参数检验前提，则采用重复测量方差分析；若前提不满足，则采用相应的非参数重复测量方法。必要时进行事后比较以明确时间点之间的差异。所有检验均为双侧检验，以 p < 0.05 为差异有统计学意义。

### 5. 相关与回归分析

连续变量之间的相关性根据分布特征采用 Pearson 或 Spearman 相关分析。对于影响因素分析，若因变量为连续变量，则采用线性回归模型；若因变量为二分类变量，则采用 Logistic 回归模型。回归结果报告相应的回归系数、比值比或标准化系数及其显著性水平，必要时提供 95% 置信区间。

## 六、方法选择理由模板

### t 检验
选择 [独立样本 t 检验 / 配对 t 检验] 的原因是：研究目标为比较两组 / 两次测量的连续变量差异，且当前数据在[正态性 / 样本关系]方面基本满足该方法要求。

### Welch t 检验
由于两组数据方差不齐，因此采用 Welch t 检验代替标准独立样本 t 检验，以提高结果稳健性。

### Mann–Whitney U / Wilcoxon
由于数据分布明显偏态、样本量较小或存在异常值，参数检验前提不充分，因此采用相应的非参数方法。

### ANOVA
研究目标为比较三组及以上独立组连续变量差异，因此优先考虑方差分析；若总体差异显著，再进行事后比较。

### 卡方 / Fisher
研究目标为比较分类变量在不同组之间的分布差异；当部分格子的期望频数不足时，采用 Fisher 精确检验。

### Pearson / Spearman
相关分析方法根据变量分布与测量水平选择：连续且近似正态时优先 Pearson，偏态或等级资料时优先 Spearman。

## 九、禁止事项

不要这样写：

- "采用合适的统计方法进行分析"
- "数据符合正态分布"但没有任何判读依据
- "使用 SPSS 26.0"但用户从未说明版本
- "所有变量均采用均值 ± 标准差表示"但数据明显偏态
- "结果有统计学意义"但没有说明检验类型或 p 值标准

应写得更具体、更可复核。
