# thesis-data-analysis

**版本**: 1.2.0
**作者**: 乐义
**语言**: 中文
**领域**: 学术数据分析

一个用于论文、毕业论文、临床实验、RCT、实验报告的数据分析 skill。

它的核心目标不是"直接跑统计"，而是：

1. 先根据研究设计、变量类型、样本关系和数据特征，判定最佳统计学路径
2. 再进行 Python 数据整理、统计分析与图表生成
3. 生成或解析 SPSS 统计分析，并与 Python 结果交叉验证
4. 输出符合论文规范的三线表
5. 最终生成接近论文 Methods 中"Statistical Analysis"部分风格的统计学方法摘要

## 设计原则

本 skill 遵循以下原则：

- **先判定统计路径，再执行统计分析** — 任何正式分析前必须先判断研究目标、变量结构、样本关系
- **至少提出 3 个关键问题** — 当研究设计或数据结构不完整时，优先提问澄清
- **软件服从统计学问题** — SPSS 和 Python 只是工具，先确定统计学路径再选择工具
- **智能判读优先于机械执行** — 即使用户指定某种方法，也必须先判断是否适合当前数据
- **结果必须可复核** — 包含研究设计说明、变量说明、方法选择理由、SPSS/Python 双验证
- **诚实可信** — 不伪造数据、不捏造显著性、不在前提不明时强行给结论

## 工作流（9个阶段）

### 阶段 1：统计路径智能判定
优先识别研究设计：

- 研究目标
- 因变量 / 自变量
- 变量类型（连续 / 分类 / 等级）
- 样本关系（独立 / 配对 / 重复测量）
- 组数 / 时间点
- 缺失值、异常值、偏态情况

输出格式：
- 研究目标、因变量、自变量、数据类型、样本关系
- 推荐统计方法、备选方法、选择理由
- 需要检查的前提假设
- 当前信息是否足够正式分析

如果信息不足，先提至少 3 个关键问题。

### 阶段 2：统计学智能判读（强制层）
当用户提到具体统计方法时，必须先做适用性判读：

- 该方法适用于什么场景
- 当前数据是否满足前提
- 若不满足，替代方法是什么
- 为什么替代方法更稳妥

**方法判读速查表**：读取 `@/Users/leyixu/.claude/skills/thesis-data-analysis/references/statistical-test-cheatsheet.md`，包含 t 检验、方差分析、卡方检验、相关分析、回归分析等各种方法的详细判读项和决策树。

### 阶段 3：数据结构与质量检查
检查数据是否可以分析：

- 每行/每列的含义是否清晰
- 缺失值情况
- 重复记录
- **异常值、极值（发现后必须阻断）**
- 编码混乱
- 变量名和格式问题

**异常值阻断规则**：
如果在数据检查中发现异常值或极值（如超出生理/物理合理范围、Z-score > 3、箱线图外1.5倍IQR、或明显偏离分布的数据点），**必须立即停止所有后续流程**，按以下步骤执行：

1. **列出所有可疑数据点**：具体数值、所在样本、出现位置
2. **评估影响**：说明这些异常值可能对统计结果产生的影响
3. **通知用户清洗**：明确告知用户需要确认或处理这些数据
4. **等待用户决策**：在用户明确回复如何处理之前，禁止进入阶段 4 及之后的任何分析步骤
5. **用户选项**：保留 / 删除 / 替换（需用户明确指定替换值）/ 分组分析

**禁止行为**：不得在发现异常值后不经用户确认就直接继续分析，或擅自删除/修改数据。

### 阶段 4：前提假设检查

参数检验前必须执行以下检查，**禁止跳过**。

**执行顺序**：独立性 → 正态性 → 方差齐性 → 样本量 → 异常值复核 → 重复测量球形检验（如适用）

**使用脚本**：`@/Users/leyixu/.claude/skills/thesis-data-analysis/scripts/assumption_checks.py`

```python
from assumption_checks import run_all_checks

# 执行完整检查
report = run_all_checks(
    groups=[group1, group2],           # 各组数据列表
    group_names=['实验组', '对照组'],   # 组名（可选）
    is_repeated=False,                  # 是否为重复测量
    data_long=None                      # 长格式数据（重复测量时需要）
)

# 检查是否可继续
if report['can_proceed']:
    print("前提满足，可继续参数检验")
else:
    print("存在前提不满足项，需选择替代方法")
```

#### 检查项说明

| 检查项 | 方法 | 判断标准 | 阻断条件 |
|--------|------|----------|----------|
| **独立性** | 人工判断 | 各观测值来自不同个体，无配对/重复关系 | 发现配对/重复时需改用对应方法 |
| **正态性** | Shapiro-Wilk (n<50)<br>D'Agostino-Pearson (n≥50)<br>Q-Q 图 | p > 0.05 且 Q-Q 图贴合对角线 | p ≤ 0.05 或图形偏离 → 改用非参数方法 |
| **方差齐性** | Bartlett (各组均正态)<br>Levene (存在非正态) | p > 0.05 | p ≤ 0.05 → Welch 校正 |
| **样本量** | 统计评估 | 最小组 n ≥ 30 | n < 5 时禁止推断；n < 30 时谨慎解释 |
| **异常值** | Z-score (>3)<br>IQR (×1.5) | 无异常值或比例 < 5% | 比例 > 5% → **强制返回阶段 3** |
| **球形假设** | Mauchly's Test (3+ 时间点) | p > 0.05 | p ≤ 0.05 → GG/HF 校正 |

#### 阻断规则

任一前提不满足时：
1. **输出警告**：明确说明哪项前提不满足
2. **给出替代方案**：非参数方法 / Welch 校正 / 数据清洗
3. **等待用户确认**：用户明确回复前禁止进入阶段 5

#### 禁止行为
- 不执行实际代码检验，仅凭主观判断"数据看起来正常"
- 前提不满足时仍直接执行参数检验而不提示用户
- 不报告具体的检验统计量和 p 值
- 大样本时仅凭 p 值判断正态性而忽略 Q-Q 图

### 阶段 5：Python 分析与图表生成
推荐工具：pandas、seaborn、matplotlib、scipy.stats、statsmodels

图表选择指南：
- 连续变量分布：直方图、密度图、箱线图、小提琴图
- 两组/多组比较：箱线图、小提琴图、点图+误差线
- 配对/重复测量：配对点图、折线图
- 相关分析：散点图+回归线
- 分类频数：条形图

### 阶段 6：SPSS 与 Python 双重验证
- 生成 SPSS 菜单路径或 Syntax
- Python 重算验证（scipy.stats / statsmodels）
- 对比结果并解释差异
- 排查不一致原因（样本筛选、缺失值处理、参数设置等）

### 阶段 7：三线表输出
- 只保留三条主要水平线（顶线、表头线、底线）
- 数据呈现规则：正态用「均值±标准差」，偏态用「中位数[Q1,Q3]」，分类用「n(%)」
- 支持 Markdown、LaTeX booktabs、CSV 格式

### 阶段 8：论文式"统计学方法摘要"
输出仿照 RCT 论文 Methods 部分的总结，包含：
- 数据概览（变量、样本量、缺失值处理）
- 变量呈现方式
- 统计方法与理由
- 软件与交叉验证方式
- 显著性标准

### 阶段 9：结果写作支持与兜底
- 提供论文结果段模板
- 明确标注局限性
- 无法执行时的替代方案（研究设计不清、只有截图、方法不适用等情况）

## 高频踩坑速查（Gotchas）

### 研究设计识别
- **不能只看"几组"，必须同时判断独立 / 配对 / 重复测量**
- **不能把重复测量当独立样本处理**
- 研究设计不清楚时，禁止进入正式统计

### 方法适用性判断
- 用户说"帮我做 t 检验"≠可以直接做，必须先判断前提
- 明显偏态数据不能直接套参数检验
- 方差不齐时优先用 Welch t 检验
- 样本量过小时不能给出强推断结论

### 数据质量
- 收到截图时不能直接重算，只能解析结果
- 变量含义不清楚时停止推断
- 分类变量编码混乱时先清洗

### 结果解读与写作
- 图表展示 ≠ 统计显著性结论
- p ≥ 0.05 时不能说"差异成立"
- 偏态分布不能用"均值±标准差"
- 必须同时报告效应量，不能只给 p 值

### SPSS vs Python 对比
- 方法不同时不能直接比数字
- 结果不一致时先排查参数设置差异
- 重要分析必须双验

用户最好提供以下信息中的尽可能多项：

- 原始数据文件或表格文本
- 每列变量的含义
- 哪个是因变量，哪个是分组变量
- 是否独立样本或配对样本
- 样本量
- 希望回答的研究问题
- 是否已有 SPSS 输出结果
- 想要的最终产物（图表 / 三线表 / 结果段 / 统计学方法段）

## 常见限制

以下情况不应直接进入正式推断统计：

- 变量含义不清
- 研究设计不清
- 只有截图没有可计算数据
- 样本量极小且前提严重不满足
- 用户指定的方法与数据结构明显不匹配

此时应先：

- 提问澄清
- 做描述性统计
- 给出数据整理模板
- 提供替代分析路径
- 明确说明局限性

## 使用示例

### 示例 1：两独立组连续变量比较
用户说："我有实验组和对照组各 30 人，比较干预后疼痛评分差异。"

输出应包括：
- 统计路径：两独立组连续变量比较
- t 检验适用性判读
- 推荐方法：独立样本 t 或 Welch t；必要时 Mann–Whitney U
- Python 代码
- SPSS Syntax
- 图表建议：箱线图 / 小提琴图 + 点图
- 三线表列：组别、n、均值±标准差、统计量、p
- 统计学方法摘要

### 示例 2：同一批患者前后比较
用户说："我有 20 名患者治疗前后平衡评分，想知道有没有改善。"

输出应包括：
- 统计路径：两配对样本连续变量比较
- 配对 t 检验适用性判读
- 推荐方法：配对 t；必要时 Wilcoxon
- 图表建议：配对点图 / before-after 折线图
- 三线表列：时间点、n、均值±标准差、统计量、p
- 统计学方法摘要

### 示例 3：相关分析
用户说："我想看肌力和步速是否相关。"

输出应包括：
- 统计路径：相关分析
- 推荐方法：Pearson；必要时 Spearman
- 图表建议：散点图 + 回归线
- 结果模板：r / rho 与 p 值写法
- 统计学方法摘要
