## ⚠️ 四、Gotchas（高频踩坑速查）

### 场景 1：文件格式错误
- **陷阱**：用户提供的不是 .docx 格式（如 .doc、.pdf、.txt）
- **后果**：转换脚本无法处理，报错或输出乱码
- **正确做法**：提前检查文件扩展名，非 .docx 格式时提示用户先转换

### 场景 2：文件路径错误
- **陷阱**：用户提供的文件路径不存在或文件名拼写错误
- **后果**：脚本执行失败，提示文件未找到
- **正确做法**：执行前用 `ls` 或 `test -f` 确认文件存在

### 场景 3：输出路径冲突
- **陷阱**：输出路径已存在同名文件，用户未指定覆盖
- **后果**：可能覆盖原有文件，造成数据丢失
- **正确做法**：询问用户是否覆盖，或自动添加序号生成新文件名

### 场景 4：特殊内容丢失
- **陷阱**：文档包含复杂表格、图片、特殊字体
- **后果**：转换后格式错乱，内容丢失或变形
- **正确做法**：转换前提醒用户检查复杂元素，转换后建议人工复核

### 场景 5：GB/T 9704 标准偏差
- **陷阱**：输出结果并非按照"标准公文格式" GB/T 9704-2012 输出
- **后果**：用户认为转换结果不符合预期
- **正确做法**：严格按照GB/T 9704 标准，不要幻想，有疑问征询用户，不要对不确定的事情自作主张。

## 五、输出规范

转换后的文档应符合以下 GB/T 9704-2012 标准：

- **纸张**：A4（210mm × 297mm）
- **页边距**：上 37mm，下 35mm，左 28mm，右 26mm
- **字体**：正文仿宋_GB2312 三号，标题小标宋二号
- **行距**：固定值 28-29 磅
- **页码**：外侧对齐，四号半角宋体
